<h2>Descrição:</h2>
Agenda de Contatos com busca
<br></br>
<h2>O que foi feito:</h2>
Foi feito uma agenda simples com a opção de cadastrar o contato, além de uma opção de buscar o contato desejado. Utilizei conhecimento básico da classe Scanner para interagir com usuário e  da ArrayList para manipulação e guardar lista de contatos.
<h2>Com quem fez:</h2>
Fiz sozinho, realizando pesquisas em sites e fóruns de java na internet como (DevMedia, stack overflow, javaprogressivo, juj e etc.) além de livros de POO diversos, apostilas, pdfs etc.
<br></br>
<h2>Como fez:</h2>
A ideia principal foi pensada, desenhada e estruturada para agenda simples. Foi definido os atributos nome e tefone para agenda ( com menu de interação), com 3 classes: pessoa, lista de contato e agenda. Na classe pessoa onde foi definido atributos com constutor, na classe listaContos foi definido os métodos cadstrar e buscar contatos além de arrayList para armazenadas as informações. E a classe agenda onde contém menu de interação com usuário.  
<br></br>
<h2>O que aprendeu:</h2>
Aprofundamento de fluxo de dados, Interação e manipulação do usuário, com sistema de cadastro e busca, utilizando classes Sanner, funcionamento das classes e melhor organização entre objetos, atributos e métodos, além de novas manipulações de listas e sua classe ArrayList, manipulação de excessões, etc.
<br></br>
