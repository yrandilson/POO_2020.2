<h2>Nome do projeto:</h2> Tarifa
<h2>Desenvolverdor(a):</h2>Antonio Irandilson

<h2>O que foi feito:</h2>
Foi realizado a proposta de atividade Tarifa, que consiste em um sistema compra de passagem, onde é possível informar o nome do passageiro, quantidade de passagens a serem compradas e valor da passagem.Utilizei conhecimento básico da classe Scanner para interagir com usuário e  da ArrayList para manipulação e guardar conjunto de dados em uma lista, nesse caso nome e telefone dos contatos de determinadas pessoas. Além de menu para interagir com o usuário onde você poderá adicionar, exibir ou remover contato da lista.
